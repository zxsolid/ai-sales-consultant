# Канал по вебхуку: чаты Авито

Бот отвечает в чатах объявлений через Messenger API. Что сделано и покрыто тестами:

- Вебхук с секретом в адресе, повторные события не обрабатываются дважды.
- Если Авито ответил ошибкой 5xx или 429, бот повторяет отправку. На 4xx не повторяет.
- Менеджер написал в чат сам: бот замолкает в этом чате на 12 часов (`AVITO_PAUSE_HOURS`), чтобы не перебивать.
- Заявки, уход без заявки и предложения выучить слово приходят менеджеру в Telegram, как и для Telegram-клиентов.
- История и начатые заявки хранятся в SQLite и не пропадают при перезапуске.

Что не проверено: работа на живом аккаунте Авито. Для этого нужен тариф с доступом к Messenger API, ключи вписываются в `.env`.

## Запуск

```bash
uvicorn app.run_avito:app --port 8000
```

В `.env`: `AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET`, `AVITO_USER_ID`, `AVITO_WEBHOOK_SECRET`. Адрес вебхука для Авито: `https://ваш-домен/avito/webhook/<AVITO_WEBHOOK_SECRET>`.
